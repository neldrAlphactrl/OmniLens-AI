# OmniLens AI

> Privacy-first AI companion with secure memory, consent controls, retention management, and verifiable deletion.

## Vision

OmniLens AI is building a privacy-first AI companion that helps users remember, organize, and act on information throughout their lives while remaining in control of their data.

Core principles:

- User-owned memory
- Explicit consent
- Retention controls
- Verified deletion
- End-to-end encryption
- Transparent auditing
